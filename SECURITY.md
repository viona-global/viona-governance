# Security

This repository contains governance infrastructure and must not contain credentials, deploy keys, customer data, product runtime code, or reusable caller-defined authorization payloads.

Report suspected governance bypasses, authority confusion, stale evidence, workflow provenance defects, or secret exposure privately to the repository owner through an authorized GitHub security channel. Do not publish exploit details or sensitive values in a public issue.

All security decisions fail closed. A missing or unverifiable security fact is not treated as approval.
