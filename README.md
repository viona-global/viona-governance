# VIONA Governance

This public repository is the central governance, authorization, merge-queue, and evidence infrastructure for VIONA.

## Current state

- The global VIONA freeze remains ACTIVE.
- This repository contains governance infrastructure only.
- Product and runtime application code are prohibited here.
- Founder Authorization Seal workflows are NOT ACTIVE.
- Merge-group governance workflows are NOT ACTIVE.
- Creating this repository grants no authority over any target repository.
- No repository transfer, deployment, merge, or production authority is implied.

## Operating rules

Every future workflow or policy activation requires separate explicit Founder authority. No workflow may mint merge authority from caller-defined free text. Governance automation must use least privilege, one-writer-per-workspace discipline, fail-closed validation, and deterministic artifact and evidence integrity checks.

The central governance repository is not a final trusted workflow source until later implementation, independent review, protection verification, and sacrificial live validation all pass.
